PRIVATE SELLER OPERATIONS

Order & delivery recovery

Admin token secret hai. Sirf HTTPS seller device par use karein. Is page ka URL protection nahi hai; API authorization enforce hoti hai. Token ya buyer details publicly share na karein.

Verified support recovery

Check actual Razorpay payment/order and identity before changing recipient email. Never accept a screenshot alone. Correcting an address sends the purchased PDF to that new address, so validate ownership independently. One recovery per order per 24 hours. Inspect ambiguous sends in Resend first.

A queued message is not a confirmed recipient delivery. Delivered status means recipient mail server accepted it, not necessarily Inbox placement or that the buyer read it.
